# Loop Crypto

> Loop Crypto is a crypto and stablecoin payment processor for merchants, billing software, and e-commerce platforms. It handles charging a wallet, storing payment methods, accepting stablecoins / ERC-20 / Solana SPL tokens, and settling to merchants in fiat or crypto — via payment links, an embeddable Pay component, and integrations with Stripe, Chargebee, and OpenPay. NOTE: Loop is winding down and folding into Lead; the service was sunset on 2026-02-13 and should not be used for new integrations.

## APIs
- [Loop Crypto API (v2)](https://api.loopcrypto.xyz/api/v2/): REST API for payments, payouts, customers, entities, merchants, tokens, and webhooks. Auth via api-key + entity-id headers.
- [Demo environment](https://demo.api.loopcrypto.xyz): test/demo host for exercising integrations.

## Docs
- [Introduction](https://docs.loopcrypto.xyz): developer documentation home.
- [Get set up](https://docs.loopcrypto.xyz/docs/get-set-up): create restricted API keys and required headers.
- [Authorization signatures](https://docs.loopcrypto.xyz/docs/authorization-signatures): verify inbound webhook payloads.
- [Loop webhooks](https://docs.loopcrypto.xyz/docs/loop-webhooks): webhook delivery, event types, and retry behavior.
- [List webhooks](https://docs.loopcrypto.xyz/api/webhooks/list-webhooks): webhook management endpoint.
- [Payouts](https://docs.loopcrypto.xyz/payments/payouts): fiat/crypto settlement and off-ramping.
- [Widget](https://docs.loopcrypto.xyz/payments/widget): embeddable Pay/PayIn checkout component.
